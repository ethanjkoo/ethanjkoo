### Projects

**[Ardent CIM App](https://github.com/ethanjkoo/intern-cim-app)**
A deal-pipeline tool built as a production internal system for an M&A advisory
firm. Tracks prospective buyers through teaser, NDA, and CIM stages, and reads
incoming email replies to classify them as signed, redlined, or declined. The
classifier is hand-written weighted pattern matching rather than an API call to
a model, backed by a 61-case regression suite. The sync engine runs under a time
budget with capped concurrency and per-deal locking so a slow third-party API
cannot hang the app.
*Next.js 15, React 19, TypeScript, SQLite, Zoho CRM API*

**[KOO Design Build](https://github.com/ethanjkoo/portfolio-website)**
Marketing site for a design-build construction firm serving federal, municipal,
and commercial clients. [Live site](Koodb.com)
*Next.js App Router, Tailwind CSS 4, Vercel*

**[Tracker Game](https://github.com/ethanjkoo/tracker-game)**
Daily goal tracker where completed goals earn medals that credit points through
an append-only ledger. Day settlement is idempotent, so re-running it never
double-credits.
*Vite, React, TypeScript, Vitest*
